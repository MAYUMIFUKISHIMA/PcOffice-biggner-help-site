# 画面写真の撮影と差し替え

初版の写真は、Windows版Excelの新規ブックに架空の会議名・決定事項・訪問件数を入力して撮影したものです。実際の社内帳票は使用していません。

## 初版で追加したい写真

|ページ|取得済み|追加する場面|
|---|---|---|
|共通01～06・09|入力欄、コピー元、転記前後|共通06の未取得枠を優先。コピー元でF2を押し、文字だけをドラッグした状態を撮影。選択色と縦線が読めるよう拡大し、次に転記先の編集状態を撮る。エラー例は実際に起きた場合のみ撮影。|
|共通07・08・10|文字の欠け、折り返し・寸法調整後、太字の見出し|ホームタブの折り返しボタン、行番号または列記号の境界にポインターを置いた状態。|
|共通11～14|保存名、ファイル一覧、用紙に収まった表、PDFの種類|印刷設定の拡大縮小メニューを開き「すべての列を1ページに印刷」を示す。PDFを開いた確認画面。|
|共通15～18|数式バー、参照する数値、計算結果|追加時はセル番地と数式の先頭の等号が読み取れる範囲を残す。|

## 手順

1. 練習用ファイルに架空の文字と数値を入力する。Excelの表示倍率を上げる。
2. 操作の直前・直後をWindowsの画面キャプチャで撮る。文字選択を撮る場合は選択色が消えていないか確かめる。
3. 対象と必要な行列見出しを残して切り抜き、操作対象を赤枠で囲む。実名・取引先・ファイル履歴・アカウント情報が写らない範囲にする。
4. PNGを images/ に保存し、該当HTMLの figure に img と日本語の alt を設定する。未取得の撮影メモを結果の説明に差し替える。
5. ローカルで画像・文字の読みやすさ・前後の手順を確認する。実帳票に固有の写真は第2段階で業務別ページに追加する。
