# 松下さんWikipedia v0.1

Windows用デスクトップ版Excelの操作を、目的から探すための手引きです。フォルダーを丸ごとコピーし、index.html をダブルクリックしてください。Microsoft Edgeなどのブラウザーで開きます。ネット接続・インストール・ビルドは不要です。サイト本体は静的HTMLとCSSのみです。

初めて使う方は、索引の「議事録に一文書いてみる」から始めます。practice/minutes.xlsx は撮影例と同じ空欄を用意した練習用ファイルです。配布時は practice フォルダーも一緒にコピーしてください。

## ページを直す・増やす

- index.html が業務別索引、help/ が詳細ページ、images/ が実画面の画像、style.css が共通の見た目です。
- 共通操作には common-01 ～ common-18 の固定IDがあります。ファイル名と main の id を一致させます。タイトル変更やカードの並べ替えでも既存のファイル名を維持します。
- 新しい共通操作は既存ページを複製し、未使用のIDを付けます。業務別には minutes-01、quote-01 のように別の接頭辞を使えます。戻り先は ../index.html#minutes または #quote とします。
- 詳細ページはタイトル直下に実際の操作画面を置き、画像の下に短い説明を添えます。操作前後の画像がある場合はその順に並べます。続けて操作の場面、番号付き手順、結果の確認、注意点、関連リンクを記入します。画像はローカルに保存し、説明する操作と結果が伝わる代替テキストを付けます。
- 索引の対応する section 内の grid にリンクを一つ追加します。新しいグループは一意の id を持つ section とページ上部のグループリンクを追加します。
- 配布前に別のフォルダーへコピーして直接開き、画像とリンクを確認します。保守用の検査はリポジトリ直下から node tools/check-links.cjs で実行できます。閲覧者にNode.jsは不要です。

## 制作段階

議事録の操作には、完成版の構成と確認済みの転記方法に基づくヘルプを掲載しています。見積書の操作は仮項目です。共通操作の写真は架空の練習データを実際のExcelで表示して撮影しました。詳しくは [撮影指示書](撮影指示書.md) を参照してください。

v1.0 では提供された帳票を読み取り専用で確認し、結合・入力欄・数式・書式・保護・印刷設定と操作上のリスクを記録します。その書式で必要な場所と手順を業務別ページにまとめ、詳しい共通操作には既存ページから案内します。公開リポジトリに掲載する画面には練習用の値を使用します。実フォーマットに合わせた検証後に配布し、利用者からの質問を基にページを改善します。
